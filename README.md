# PHP Sign Up Form

A basic PHP implementation of a user registration form.

## Structure
- `index.php`: The frontend form.
- `signup.php`: The backend logic to process form data.
- `style.css`: Basic styling for the UI.

## How to use
1. Move these files to your PHP-enabled server directory (e.g., `htdocs` in XAMPP).
2. Open `localhost/your-folder-name/index.php` in your browser.
3. Fill the form and submit to see the results.
